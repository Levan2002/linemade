TEED: Tiny and Efficient Edge Detector

Linemade’s line drawings are made on the device with TEED, by Xavier Soria Poma, Yachuan Li, Mohammad Rouhani and Angel D. Sappa. The model was converted to run with Core ML.

Source: github.com/xavysp/TEED. License: MIT.
